# Активатор Лицензий (C++)

Активатор написан только в образовательных целях и для любителей эл-теха:). Aктуален для версии 1.0.0.0. После запуска вы получите файл с ключем внутрию(Лучше запускать из той же папки где и программа).ОБРАЩУ ВНИМАНИЕ АКТИВАТОР ИСПОЛЬЗУЕТ ИНТЕРНЕТ ДЛЯ СИНХРОНИЗАЦИИ ВРЕМЕНИ

## 🚀 Основные возможности

* **Синхронизация через NIST:** Использует библиотеку `WinINet` для получения текущей даты из HTTP-заголовков Google (GMT/UTC). Это делает генератор устойчивым к ручному изменению даты в Windows.
* **Пользовательский шифр:** Реализует подстановочный шифр (символы `H, M, K, J...`) для преобразования математических результатов в читаемый лицензионный ключ.
* **Автоматизация:** Программа сама создает файл `License.txt` в текущей директории в формате, который ожидает целевое ПО.
* **Надежные вычисления:** Используются 64-битные целые числа (`long long`), что полностью соответствует поведению `Int64` в C# и предотвращает ошибки переполнения.

## 🛠 Требования

* **ОС:** Windows (необходима библиотека `wininet.lib`).
* **Компилятор:** MinGW (GCC) или MSVC (Visual Studio).
* **Стандарт C++:** C++17 или выше.

## 📂 Структура проекта

* `src/main.cpp` — Основной код (синхронизация времени + генерация ключа).
* `CMakeLists.txt` — Конфигурация сборки для CLion / VS Code.


## 🔨 Инструкция по сборке

### Через MinGW (Командная строка)
```bash
g++ src/main.cpp -o activator.exe -lwininet -static
```
### Через CMAKE (Командная строка)
```bash
mkdir build
cd build
cmake ..
cmake --build .
```
